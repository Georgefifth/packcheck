Build a browser utility that prepares submission ZIPs from local files. This is the only active product; the user requested removal of the prior project and deployment.

- Work only in this new project. Do not inspect pre-existing unrelated local projects.
- Preserve input files. No content uploads, analytics, accounts, or persistent storage.
- Show exact archive contents and check explicit requirements. Do not claim to interpret arbitrary assignment prose, grade work, convert formats, or submit to an LMS.
- Credit maintained third-party libraries and prior art.
- Validate actual ZIP contents and byte preservation using headless Playwright Firefox. Inspect screenshots.
- Keep English and Chinese interfaces compact and accessible.
- GitHub publication and github.io deployment are authorized.
